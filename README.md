# 🌲 Sounds of the Forest (Spooky Forest)

An interactive, spooky web application exploring the mysterious nocturnal sounds of wildlife found in the forests of Quebec and Ontario, Canada.

---

## 🦉 Overview

Have you ever been camping or walking in the dark woods and heard a chilling shriek, ghostly wail, or eerie chattering? Often, the scariest sounds in the wild come from familiar, harmless, or misunderstood animals!

**Sounds of the Forest** lets you listen to mystery sounds from the night forest and test your courage—before revealing the creature responsible.

---

## ✨ Features

- **Mystery Sound Player**: Click *"Listen... if you dare"* to hear a randomly selected nocturnal forest creature call in the dark.
- **The Big Reveal**: Click *"Show me who it is"* to reveal the animal's photo, name, and an educational blurb explaining why it makes that eerie noise.
- **Meet the Animals Gallery**: Browse a dedicated soundboard grid showcasing all the featured animals. Click any card to play their sound on demand.
- **Spooky Atmosphere**: Thematic night-mode design, spooky typography, and responsive layout built for all screen sizes.
- **Zero Dependencies**: Pure HTML5, CSS3, and vanilla JavaScript—no build step, bundlers, or external packages required.

## 🚀 Getting Started

Since this is a lightweight static web app, no installation or compilation is needed.

### Option 1: Open Directly
Simply open `index.html` in any modern web browser:
```bash
open index.html
```

### Option 2: Run with a Local Web Server
If you prefer running via a local server (e.g., with Python):
```bash
# Python 3
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
